News Assistant

From long videos to the stories that matter.

Distills notable news from 2–3 public videos, cross-checks sources, and prepares concise, evidence-linked summaries for human review.

EducationHealth Current affairsUp to 5 stories per batch

What does the Agent do?

Instead of watching multiple sources and taking notes by hand, the Agent brings relevant coverage into one briefing with sources, publication dates, and video timestamps.

01

Check sources

Evaluates sources against the agreed criteria for verification badges and recognized, reputable publishers.

02

Merge and compare

Identifies duplicate stories, compares claims, and flags disagreements or missing official announcements.

03

Summarize with evidence

Selects up to five qualifying stories, with key facts, why they matter, sources, and video timestamps.

Workflow

The user provides the videos. The Agent returns a draft for review before the final report is saved.

Receive inputs2–3 URLs or files, about 30 minutes total
ValidateSource, publication date, access, and audio
AnalyzeExtract content, timestamps, and key stories
DistillMerge duplicates, compare, and rank
Human reviewRevise as needed, then save Markdown

Editorial criteria

Topic priorities

  • Education, health, then current affairs.
  • Exam-related news must have nationwide scope.
  • Prioritize everyday health, prevention, and vaccination.
  • Include up to five qualifying stories; do not pad the list.

Transparent verification

  • Merge duplicate coverage into one item.
  • Show conflicting claims clearly without jumping to conclusions.
  • State when no official announcement has been found.
  • Include a source, publication date, and video timestamp for every item.

Scope and limitations

This is a showcase page, not an interactive interface. It does not connect to Hermes, Lark, APIs, data, or Agent permissions. Visitors cannot submit tasks to the bot.

The Agent currently requires the user to provide videos; it does not automatically scan for news or run on a schedule. URLs may be inaccessible. Unclear audio or unverifiable information will be flagged or skipped. The user must review the draft. The Agent does not replace public authorities or medical professionals.

Status, stated plainly The bot passed a Lark group messaging check. No completed video-analysis report has been confirmed in the project documents, so this page does not claim that the analysis workflow has run successfully.
